# Настройка пользовательского токена VK

Ниже безопасный пример получения и использования токена:

```python
access_token = 'your_access_token'
```

Как получить токен:
1. Откройте https://vkhost.github.io/
2. Выберите `VK Admin`
3. Разрешите доступ
4. Скопируйте значение `access_token` из URL

Важно: не публикуйте реальный токен в репозитории.
