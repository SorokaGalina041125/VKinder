# VKinder — бот для знакомств ВКонтакте

[![Python](https://img.shields.io/badge/Python-3.11-blue.svg)](https://www.python.org/)
[![PostgreSQL](https://img.shields.io/badge/PostgreSQL-compatible-blue.svg)](https://www.postgresql.org/)
[![VK API](https://img.shields.io/badge/VK-API-blue.svg)](https://dev.vk.com/)

**VKinder** — учебный проект на Python, который помогает искать кандидатов во ВКонтакте по заданным критериям, показывает анкеты в сообщениях сообщества и сохраняет историю взаимодействия в PostgreSQL.

## 🚀 Реализованный функционал

### 1. Поиск по возрасту, полу и городу

Пользователь задает критерии через диалог с ботом, после чего они сохраняются в базе данных и используются для поиска кандидатов через VK API.

---

### 2. Получение популярных фотографий

Для найденных кандидатов бот загружает фотографии из профиля и сохраняет наиболее популярные изображения по сумме лайков и комментариев.

---

### 3. Вывод анкеты в чат

Бот отправляет имя, фамилию, ссылку на профиль и фотографии кандидата прямо в сообщения сообщества. Пользователь может переходить к следующей анкете кнопкой **"Следующий"**.

---

### 4. Избранное

Анкету можно сохранить в избранное. Список избранных кандидатов доступен отдельной командой из чата.

---

### 5. Черный список

Анкету можно скрыть через черный список. Такие кандидаты исключаются из последующих показов.

---

### 6. Кнопки и payload

Основные действия бота работают через клавиатуры VK и `payload`, что делает сценарии в чате стабильнее и удобнее.

---

### 7. Лайки фотографий

Для фотографий поддержаны действия лайка и снятия лайка через VK API с сохранением статуса в базе данных.

---

### 8. Пагинация поиска

Поиск поддерживает `offset` и повторные партии кандидатов, чтобы бот не крутился по одной и той же начальной выдаче.

---

### 9. Сохранение просмотренных анкет

Бот запоминает просмотренные, избранные и заблокированные анкеты, чтобы не показывать их повторно без необходимости.

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/SorokaGalina041125/VKinder.git
cd VKinder
```

### 2. Создание виртуального окружения

```bash
# Windows
py -3.11 -m venv .venv
.venv\Scripts\activate

# Linux / Mac
python3.11 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и заполните значения:

```bash
copy .env.example .env
```

Пример `.env`:

```env
# Database
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=vkinder

# VK Tokens
VK_USER_TOKEN=your_vk_user_token
VK_GROUP_TOKEN=your_vk_group_token
VK_GROUP_ID=your_group_id
```

`VK_GROUP_ID` можно не указывать, тогда бот попробует определить его автоматически.

### 5. Настройка токенов VK

#### `VK_GROUP_TOKEN`

Это токен сообщества. Получается в настройках сообщества:

1. `Управление`
2. `Работа с API`
3. `Ключи доступа`
4. Создать ключ для сообщений сообщества

#### `VK_USER_TOKEN`

Это пользовательский токен обычного аккаунта VK. Он нужен для поиска кандидатов, работы с городами, фотографиями и дополнительными методами VK API.

Получить его можно так:

1. Откройте [vkhost.github.io](https://vkhost.github.io/)
2. Выберите `VK Admin`
3. Авторизуйтесь
4. Разрешите доступ
5. Скопируйте `access_token` из URL

Если `VK_USER_TOKEN` невалиден или истек, поиск работать не будет.

### 6. Запуск базы данных

Для разработки нужен доступный PostgreSQL. Бот сам проверяет существование базы `vkinder`, создает таблицы и синхронизирует часть старой схемы при запуске.

### 7. Запуск бота

```bash
python main.py
```

После успешного старта в логе должно появиться:

```text
INFO - Инициализация БД
INFO - База данных готова
INFO - Бот запущен и готов к приему сообщений
```

## 🔧 Важные замечания

- Бот использует **Bots Long Poll**, а не обычный user long poll.
- Для работы поиска нужны **два разных токена**: сообщества и пользователя.
- Если бот получает сообщения, но не ищет кандидатов, в первую очередь проверьте `VK_USER_TOKEN`.
- Если в проекте уже была старая база, схема частично синхронизируется автоматически при старте.

---

## 📌 Что проверить, если бот не отвечает

1. Включены сообщения сообщества
2. Включен Bots Long Poll
3. У токена сообщества есть права на сообщения
4. В `.env` корректный `VK_GROUP_TOKEN`
5. В `.env` корректный `VK_USER_TOKEN`
6. PostgreSQL запущен и доступен
7. В `bot.log` появляются новые записи после отправки сообщения
