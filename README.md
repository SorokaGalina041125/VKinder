**VKinder** — учебный проект, разработанный в рамках изучения Python, работы с VK API и реляционными базами данных. Бот помогает находить людей для знакомств на основе заданных критериев с использованием взвешенной системы ранжирования.

## 🚀 Реализованный функционал

### 1. Поиск по возрасту, полу и городу

Поиск кандидатов осуществляется через метод `users.search` VK API. Пользователь задает критерии через диалог с ботом (выбор пола, ввод возраста и города), после чего параметры сохраняются в базе данных и используются для формирования запроса.

---

### 2. Получение трех популярных фотографий

Для каждого найденного кандидата через метод `photos.get` загружаются фотографии из профиля. Сортировка выполняется по сумме лайков и комментариев (`likes_count + comments_count`). Три наиболее популярных фото сохраняются в базу данных и используются для отображения.

---

### 3. Вывод информации о кандидате в чат

Информация о кандидате (имя, фамилия, ссылка на профиль) формируется в текстовом сообщении, а три фотографии передаются через параметр `attachment` метода `messages.send`. Пользователь может переключаться между кандидатами с помощью кнопки "Следующий".

---

### 4. Сохранение в избранное

При нажатии кнопки "В избранное" ID кандидата сохраняется в таблице `viewed_users` с флагом `is_favorite = True`. Список избранных доступен по кнопке "Избранное".

---

### 5. Просмотр списка избранных

Бот формирует список избранных кандидатов, запрашивая из базы данных записи с `is_favorite = True`. Для каждого кандидата выводится имя, фамилия и ссылка на профиль.

---

### 6. Черный список

При нажатии кнопки "В черный список" ID кандидата сохраняется в таблице `viewed_users` с флагом `is_blocked = True`. При последующих поисках эти кандидаты автоматически исключаются из выдачи.

---

### 7. Кнопки в чате

Все действия бота реализованы через интерактивные клавиатуры VK с использованием `payload` — скрытых данных, передаваемых при нажатии. Это позволяет избежать парсинга текстовых команд и делает взаимодействие с ботом более надежным.

---

### 8. Лайки на фотографии

Для каждой фотографии доступны кнопки "Лайк" и "Убрать лайк". При нажатии отправляется запрос через метод `likes.add` или `likes.delete` VK API. Статус лайка сохраняется в таблице `likes` для синхронизации с интерфейсом.

---

### 9. Фотографии с отметками пользователя

Помимо фотографий из профиля, бот также запрашивает фотографии, где пользователь был отмечен, через метод `photos.get` с параметром `album_id = 'wall'`. Эти фото объединяются с основными для расширения набора изображений.

---

### 10. Обход лимита 1000 человек

Для преодоления ограничения VK API в 1000 результатов поиска используется два подхода:

- **Пагинация через offset** — последовательное увеличение смещения при каждом запросе.
- **VKScript + execute** — выполнение до 25 запросов за один вызов, что позволяет собрать до 2500 кандидатов. Скрипт на языке VKScript внутри метода `execute` циклически запрашивает новые порции данных.

---

### 11. Поиск по интересам

Бот анализирует интересы пользователя и кандидатов: группы (`groups.get`), музыку (`audio.get`), книги (поле `books` в профиле) и текстовые интересы (поле `interests`). Пересечения вычисляются с помощью множеств (`set`), и результат используется в системе ранжирования.

---

### 12. Взвешенное ранжирование

Каждый критерий поиска имеет свой вес:

- Возраст — 0.3
- Интересы — 0.4
- Город — 0.1
- Общие друзья — 0.2 (заглушка, так как API друзей требует дополнительных прав)

Внутри интересов веса распределены:

- Группы — 0.4
- Музыка — 0.35
- Книги — 0.25

Итоговый скор кандидата вычисляется как сумма взвешенных оценок по каждому критерию. Кандидаты сортируются по убыванию скора, и пользователь видит наиболее подходящих первыми.

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/SorokaGalina041125/vkinder.git
cd vkinder
```

### 2. Создание виртуального окружения

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

Пример `.env`:

```env
# VK Tokens
VK_GROUP_TOKEN=your_group_token
VK_USER_TOKEN=your_user_token

# Database
DB_HOST=localhost
DB_PORT=5432
DB_NAME=vkinder
DB_USER=postgres
DB_PASSWORD=your_password
```

### 5. Запуск базы данных

```bash
# Для разработки (локальный PostgreSQL)
# Убедитесь, что PostgreSQL 18 запущен

# Для тестов (Docker)
docker compose -f docker-compose.test.yml up -d
```

### 6. Запуск бота

```bash
python main.py
```
